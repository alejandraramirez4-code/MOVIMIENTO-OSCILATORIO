## 🌟 Características Principales

- 📖 **Experiencia Editorial de Cuaderno Virtual:** Transición fluida entre páginas, encabezados con numeración formal, diseño adaptativo e intuitivo.
- 📐 **Motor Matemático KaTeX:** Fórmulas físicas y deducciones matemáticas en $\LaTeX$ renderizadas con nitidez tipográfica profesional.
- 📊 **Plano Cartesiano Interactivo GeoGebra en Canvas 2D:**
  - Lienzo milimetrado mayor y menor.
  - Generación continua de la función armónica sinusoidal $x(t) = A\cos(\omega t + \phi)$.
  - Herramientas de navegación: Desplazamiento (Pan), Zoom In / Zoom Out y restablecimiento de vista.
  - Paleta de personalización gráfica: cambio de color de la curva, grosor de trazo y tipo de línea (continua, discontinua, punteada).
  - Sonda de inspección de coordenadas $(t, x)$ en tiempo real.
- ⚙️ **Simulador Físico Masa-Resorte en Tiempo Real:**
  - Animación del resorte helicoidal y oscilación del bloque con cálculo de física newtoniana.
  - Monitoreo instantáneo de la conservación de la **Energía Mecánica Total** ($E_k + E_p = E_T$) mediante barras de energía dinámicas.
  - Sliders interactivos para variar Amplitud ($A$), Masa ($m$), Rigidez ($k$) y Ángulo de Fase inicial ($\phi$).
- 🧮 **Ejercicios Prácticos de Ingeniería con Calculadora Reactiva:**
  - Aplicados a la realidad regional (aislamiento de vibraciones en compresores y monitoreo sísmico en el Viaducto César Gaviria Trujillo).
  - Metodología cromática estandarizada UTP (Datos conocidos en azul, Incógnitas en rojo, Fórmulas, Resultados resueltos en naranja y Conclusiones técnicas).
  - Calculadoras dinámicas que recalculan todos los parámetros al cambiar los valores de entrada.
- 🔍 **Glosario Técnico con Búsqueda en Vivo:** Filtrado instantáneo de más de 12 conceptos y leyes clave del M.A.S.
- 📱 **Modo Pantalla Completa y Drawer de Miniaturas:** Visualización inmersiva y navegación rápida a cualquier página mediante vista en cuadrícula.

## 🔬 Laboratorio y Simulador Virtual (Página 7)

El laboratorio interactivo integra un motor físico y gráfico programado en Canvas 2D sin librerías externas pesadas:

1. **Simulación Dinámica Masa-Resorte:**
   - Ecuación del movimiento: $x(t) = A \cos(\omega t + \phi)$
   - Frecuencia angular natural: $\omega = \sqrt{\frac{k}{m}}$
   - Periodo: $T = \frac{2\pi}{\omega}$
2. **Conservación de la Energía Mecánica:**
   - Energía Cinética: $E_k(t) = \frac{1}{2} m [v(t)]^2$
   - Energía Potencial Elástica: $E_p(t) = \frac{1}{2} k [x(t)]^2$
   - Energía Total Constante: $E_T = E_k + E_p = \frac{1}{2} k A^2$
3. **Controles Interactivos:**
   - **Amplitud ($A$):** $0.05\text{ m}$ a $0.25\text{ m}$ (paso de $0.01\text{ m}$).
   - **Masa ($m$):** $0.5\text{ kg}$ a $5.0\text{ kg}$ (paso de $0.1\text{ kg}$).
   - **Rigidez ($k$):** $10\text{ N/m}$ a $150\text{ N/m}$ (paso de $5\text{ N/m}$).
   - **Fase inicial ($\phi$):** $0\text{ rad}$ a $2\pi\text{ rad}$ (paso de $0.1\text{ rad}$).
   - Botones de **Pausar / Reanudar** y **Reiniciar Tiempo**.

## 🧮 Calculadoras Interactivas y Metodología UTP

Los ejercicios de las páginas 9 y 10 implementan el **protocolo institucional de resolución de problemas en 5 pasos**:

1. 🔵 **Identificación de Datos Conocidos:** Parámetros proporcionados por el problema con sus unidades correspondientes en el S.I.
2. 🔴 **Identificación de Incógnitas:** Variables objetivo que se deben determinar.
3. 📐 **Fórmulas Físicas y Despejes:** Modelo matemático y deducción analítica.
4. 🟠 **Sustitución y Despeje Resuelto:** Cálculo numérico explícito con etiquetas de estado.
5. ✅ **Validación Física y Conclusiones de Ingeniería:** Interpretación práctica de los resultados y consideraciones de diseño estructural/mecánico.

> **Interactividad:** Modifica los valores en los campos de entrada de las calculadoras para ver cómo se recalculan automáticamente la frecuencia angular, el periodo, la velocidad pico y la aceleración máxima, así como el análisis técnico.

  - Variables CSS (Custom Properties) para un tema cromático consistente.

    - *Playfair Display* (títulos editoriales de estilo académico).

  - Arquitectura orientada a estado (`AppState`).

  - Renderizado dinámico de energía y reactividad en tiempo real.
- **KaTeX (v0.16.11):** Motor de renderizado $\LaTeX$ ultrarrápido vía CDN para visualización matemática impecable.

5. Espera aproximadamente 1 o 2 minutos. GitHub te entregará una URL pública similar a:

## 📤 Cómo Subir este Proyecto a GitHub

### Opción A: Mediante la Web de GitHub (Sin instalar programas)
1. Inicia sesión en [GitHub](https://github.com/) y haz clic en el botón verde **New** para crear un nuevo repositorio.
2. Asígnale un nombre (por ejemplo: `fisica3-cuaderno-interactivo`).
3. Puedes dejarlo en **Public** y no marcar la casilla de agregar README (ya lo tenemos listo aquí). Haz clic en **Create repository**.
4. En la pantalla siguiente, haz clic en el enlace **"uploading an existing file"** (subir un archivo existente).
5. Arrastra todos los archivos de esta carpeta:
   - `index.html`
   - `style.css`
   - `app.js`
   - `README.md`
   - La carpeta `imagenes/` con sus contenidos
6. En la parte inferior, escribe un mensaje de commit (por ejemplo: *"Versión inicial del Cuaderno Interactivo de Física 3"*) y haz clic en **Commit changes**.

---

### Opción B: Mediante GitHub Desktop
1. Abre **GitHub Desktop**.
2. Ve a **File** > **Add Local Repository...** (o pulsa `Ctrl + O`).
3. Selecciona la carpeta donde se encuentra este proyecto.
4. Si te indica que no es un repositorio Git, haz clic en **"create a repository"**.
5. Haz clic en **Publish repository** para subirlo directamente a tu cuenta de GitHub.

---

### Opción C: Mediante la Terminal / Git CLI
Si tienes Git instalado en tu computadora:

```bash
# 1. Inicializar el repositorio en la carpeta del proyecto
git init

# 2. Agregar todos los archivos al control de versiones
git add .

# 3. Crear el primer commit
git commit -m "feat: publicación inicial Cuaderno Virtual Interactivo de Física 3 UTP"

# 4. Renombrar la rama a main
git branch -M main

# 5. Vincular con tu repositorio remoto en GitHub (reemplaza con tu URL)
git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git

# 6. Subir el proyecto a GitHub
git push -u origin main
```
